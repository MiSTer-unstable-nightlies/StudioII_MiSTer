RCA Studio II Bidirectional ST2/BIN Converter
August 22, 2026
Elle Ball

this tool converts RCA Studio II cartridge files between .st2 and .bin formats. Windows-only. You must have Python 3 (3.14.7 used) installed on your system and added to your system's PATH for the background script to execute properly.

note: not round-trip lossless, as .bin files do not contain .st2 header information. bin->st2 merely prepends a valid header and cannot reconstruct the missing header.

1. drag and drop the .bin or .st2 files onto Convert_ST2_BIN.bat
2. command prompt remains open to review results

details:
st2->bin: strips the `RCA2` header extracts the code blocks. removes sparse RAM gap padding
bin->st2: pads raw binary data to 256-byte alignment. assigns valid hardware target pages, skipping reserved regions. writes the required `RCA2` header. files exceeding 16KB are rejected
